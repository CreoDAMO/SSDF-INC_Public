SSDF Inc. (parent holding company) and AMAIMA Inc. (operating subsidiary) operate a production cryptographic AI infrastructure platform. AMAIMA — Advanced Multimodal AI Multi-Intelligence Architecture — provides FHE inference, post-quantum attestation, court-admissible verification proofs, and sovereign-grade compliance architecture. Both entities are Florida C-corporations with U.S.-citizen ownership, organized April 6, 2026. The infrastructure is deployed at scale, the cryptographic primitives are compiled from source, the patents are filed, and the compliance mappings tie to specific running components rather than documentation overlay.

  • Cryptographic Sovereign Speech Synthesis — every output carries a signed, externally verifiable proof bundle

  • Visual multi-agent workflow studio with FHE-aware edges — data stays encrypted across the execution graph

Sovereign Ledger Infrastructure

  • Verified across a 260+ test suite spanning both Rust core and TypeScript client implementations
